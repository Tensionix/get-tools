Audion Get Tools ставит, обновляет и удаляет программы Windows через WinGet: вы отмечаете нужное галочками и нажимаете одну кнопку. Руководство описывает то, что полезно знать при работе: как забрать дистрибутив, ничего не устанавливая, как привести в порядок рантаймы Visual C++ и как пользоваться AI-подбором пакетов.

Устройство проекта, состав сервисов и правила разработки описаны в README - это техническая документация, здесь её нет.

## Каталог WinGet: наборы, установка, обновление

Главное окно программы это каталог: 126 пакетов в двенадцати блоках - Система, Разработка, AI, PKMS и заметки, Office и документы, Медиа (изображения, звук, видео), Браузеры, VPN и связь, Железо и утилиты, MSVC рантайм 2015+ и Advanced: MSVC 2005-2013. Блок это карточки с галочками; над списком поле фильтра по имени и ID, у каждого блока кнопки `Отметить блок` и `Снять блок`, а ряд `Профили выбора` сверху (Снять всё, Минимум, Dev, Медиа, Сеть) отмечает типовой набор одним нажатием, после чего правится любая карточка. Кнопки `Экспорт YAML` и `Импорт YAML` в строке навигации сохраняют текущие галочки в файл и возвращают их, хоть на другой машине.

Каждый блок это обычный список ID в настройках: своя программа добавляется строкой в файл или кнопкой `Добавить ID в список` из окна `Установка, удаление по ID`, где есть и `Поиск` по каталогу WinGet, и установка или удаление по введённому ID.

| Окно | Что делает |
| --- | --- |
| `Установить выбранные` | Сначала сканирует систему и показывает только то, чего ещё нет, потом ставит отмеченное без вопросов Y/N, с живым прогрессом в журнале. |
| `Предпросмотр обновлений` | Показывает список `winget upgrade` как «имя, ID, текущая, доступная» и ничего не меняет. |
| `Обновить выбранные`, `Обновить доступные`, `Обновить всё доступное` | Обновления по блокам каталога, по списку WinGet с галочками, или всё разом. |
| `Закрепить выбранные` | Ведёт `config\pins.txt`: отмеченные установленные пакеты получают blocking-pin и не обновляются, пока закрепление не снято. |
| `Удалить выбранные ID` | Установленное по тем же блокам; системные и рантаймовые ID защищены и требуют отдельной галочки. |
| `Обновить WinGet` | Обновляет сам менеджер пакетов; после него программу нужно перезапустить. |
| `Импорт / экспорт` | `winget export` в JSON с настроенной машины и `winget import` на новой, с галочками про версии, обновление установленных и недоступные пакеты. |

Всё, что меняет систему, перед запуском спрашивает подтверждение; скачивание и проверки идут сразу.

## Скачивание без установки

У каждой программы в списке справа от названия есть маленькие кнопки. Они не влияют на галочку: нажатие кнопки не отмечает и не снимает выбор, работа с чекбоксами остаётся прежней.

| Кнопка | Что делает |
| --- | --- |
| Зелёная стрелка вниз | Скачивает установщик программы в `output\Downloads` и ничего не устанавливает. |
| Малиновая коробка | Скачивает zip-архив или standalone-сборку - ту, которую не нужно устанавливать. Появляется только у программ, у которых такая сборка действительно есть. |
| Синяя стрелка вверх | Открывает в браузере страницу загрузки: раздел релизов на GitHub, страницу TechPowerUp или сайт разработчика. |

Малиновая кнопка есть примерно у четверти списка - у 29 программ. Это не прихоть: наличие архива проверено по каждому пакету, и кнопка не показывается там, где архива нет, чтобы вы не жали её впустую. Среди них Notepad++, Everything, OBS Studio, VLC, Telegram, FFmpeg, Node.js, MKVToolNix, Audacity, Sysinternals, Rufus, yt-dlp, SumatraPDF, Tabby, Rclone, RClone Manager.

Иногда сборка есть у разработчика, но её нет в каталоге WinGet - так у Tabby и RClone Manager. Тогда файл берётся прямо со страницы выпусков, а кнопка ведёт себя как обычно. Обе кнопки в таком случае берут файлы из одного выпуска, поэтому установочная и портативная версии всегда одной версии. У RClone Manager это ещё и свежее: в каталоге WinGet лежит только установщик, и он отстаёт от того, что уже выложил разработчик.

Это же выручает, когда WinGet просто не может отдать файл: если у программы есть страница выпусков на GitHub, Audion Get Tools сам поищет нужную сборку там. Все проверки на месте - чужие системы, другая разрядность, контрольные суммы и отладочные файлы отбрасываются, и если однозначного файла нет, кнопка честно скажет об этом, а не скачает что попало.

Зачем это нужно, если есть обычная установка:

- дистрибутив можно унести на другую машину или сохранить на случай работы без сети;
- некоторые программы, установленные своим дистрибутивом, умеют больше, чем их пакет WinGet. Так, PowerShell из установщика Microsoft добавляет пункты в контекстное меню проводника и дальше обновляется сам, а установленный через WinGet - нет;
- на странице загрузки можно выбрать нужную сборку руками: другую разрядность, portable-версию, предыдущий выпуск.

Рядом с `Google Chrome (веб-установщик)` стоит отдельная кнопка скачивания - она забирает тот же веб-установщик, но не запускает его.

Куда всё попадает:

| Папка | Что там |
| --- | --- |
| `output\Downloads` | Установщики - россыпью, без подпапок. Их берут, ставят и забывают. |
| `output\Portable\<Программа>` | То, что работает без установки: архивы и standalone-сборки. Каждая в своей папке с именем программы: `output\Portable\Notepad++`, `output\Portable\Rufus`. |
| `output\Install\<Набор>` | То, что ставится в систему, например `output\Install\MSVC All-in-One (TechPowerUp)`. |

Имя папки - это имя программы так, как её пишет разработчик. Никаких `Google.Chrome` и подчёркиваний. А вот внутри папки всё лежит с теми именами, с которыми пришло от разработчика.

Разделение идёт по смыслу, а не по расширению: набор MSVC ставится в систему, поэтому лежит в `Install`, хотя приходит zip-архивом - рядом с архивом Audion Get Tools распаковывает его содержимое, чтобы `install_all.bat` был под рукой.

Всё это лежит в `output` и очищается вместе с ним при очистке рабочих папок - так и задумано: портативная сборка не должна возить с собой гигабайты установщиков. Нужное перенесите к себе, остальное просто скачайте заново.

## Загрузки от вендоров

WinGet отдаёт текущий выпуск программы. Раздел `Загрузки от вендоров` берёт каталог самого производителя и показывает все версии, которые он когда-либо публиковал - с датой выпуска, новые сверху. Так держат склад версий: свежую и ту, на которой всё работало.

Это один экран на всех производителей: вкладки вверху выбирают, чей каталог смотреть, активная подчёркнута синим; у Windows под ними второй ряд вкладок, `Версия`, `Приложения`, `Драйверы`, потому что полей там больше, чем помещается на один экран, а ряд опций над ними общий; на странице `Версия` продукт, платформа, редакция и язык стоят прямо над карточками, и смена любого из них сразу видна в подписях сборок; сразу под ними одной строкой идут опции (распаковка zip, удаление архива, сборка ISO, папка без подпапок), ниже платформы и продукты, а список версий и кнопки общие. Каждый блок начинается с ряда макро-кнопок: `Вид образа` (Business, Consumer, Только Pro) и `Набор приложений` у Windows, `Выбрать` над карточками версий у всех.

| Производитель | Что есть |
| --- | --- |
| Windows (UUP dump) | Каждая сборка Windows 11 и Windows 10 из каталога UUP dump, каждое накопительное обновление своим номером и датой, плюс Insider; x64 и ARM; язык и редакция переключателями. Скачивается пакет скриптов, а ISO собирается на этой машине из файлов самой Microsoft. |
| TechPowerUp | Каталог сайта по разделам, у каждой записи вся история версий с датой и размером. Драйверы: AMD Radeon и чипсет Ryzen, Intel графика (Arc, iGPU), Wi-Fi, Bluetooth, Ethernet и NPU, Qualcomm Snapdragon X. Утилиты: DDU, NVCleanstall, NVIDIA Profile Inspector, ThrottleStop, DRAM Calculator for Ryzen, Samsung Magician, Visual C++ Runtimes AIO, MemTest64. Мониторинг: GPU-Z, CPU-Z, AIDA64 Extreme, ZenTimings, Real Temp. Бенчмарки: 3DMark, PCMark 10, Cinebench, FurMark, Prime95, Unigine Superposition и Heaven, GravityMark, Linpack Xtreme, ATTO Disk Benchmark. BIOS видеокарт: NVIDIA NVFlash, AMDVBFlash. Файл идёт по подписанной ссылке TechPowerUp. Версия это одна карточка: зелёная стрелка качает установщик, багровый значок архива портативную сборку той же версии, пустое место значит, что такого файла нет; кнопка «Портативные» оставляет в списке версии с портативной сборкой, и отметка значит этот файл. Драйверы NVIDIA и DLSS остаются на вкладке NVIDIA. |
| NVIDIA | Драйверы Game Ready и Studio по поколению чипов: RTX 50, 40, 30, 20, GTX 16, 10, 900, 700, 600, 500, 400, настольные и ноутбучные. NVIDIA App и Broadcast - текущие установщики. CUDA Toolkit - все выпуски из архива. DLSS, DLSS Frame Generation и DLSS Ray Reconstruction - все версии библиотек с TechPowerUp. |
| Blackmagic Design | DaVinci Resolve и Resolve Studio, Fusion, Blackmagic RAW, Desktop Video, Camera Setup и весь остальной каталог - 45 продуктов для Windows, Windows ARM, macOS и Linux. |
| Affinity | Affinity 3 от Canva - единое бесплатное приложение, только текущий выпуск, exe и msix для x64 и ARM, dmg для macOS. Photo 2, Designer 2 и Publisher 2 - все выпуски 2.x со страниц обновлений Serif, на Windows каждая версия как msix и как exe. |

Windows из UUP dump - это способ получить образ «на конкретный месяц», с обновлениями уже внутри, не дожидаясь, когда Microsoft обновит свои носители. Microsoft раздаёт систему теми же UUP-файлами, которыми ставит обновления, а UUP dump ведёт каталог всего, что видел. Карточка версии здесь - это сборка, например `24H2 26100.9278 - 27 Aug 2026`; в фильтр можно набрать выпуск или месяц. Скачивается небольшой пакет со скриптом `uup_download_windows.cmd`, и есть два пути:

- галочка `Сразу собрать ISO`: после распаковки скрипт запускается в своём окне консоли, скачивает файлы с серверов Microsoft через aria2 и собирает загрузочный ISO. Сборка идёт не в папке назначения, а в папке `UUP` в корне того диска, где стоит программа (например `E:\UUP`): скрипту нужен короткий путь без пробелов, и программа создаёт его сама. Готовый образ переносится в папку назначения, в `Vendors\Windows (UUP dump)` или прямо в неё при галочке `Сразу в папку назначения`; если образ с таким именем там уже лежит, новый попадает в подпапку с датой и временем, старый не перезаписывается. Скрипту нужны права администратора, которые он спросит сам;
- галочка `Удалить кэш после ISO` появляется вместе с предыдущей: после переноса образа папка сборки в `UUP` со скриптами и 9 ГБ файлов Microsoft удаляется. Без неё папка остаётся, и ту же сборку можно пересобрать с другим набором приложений без повторного скачивания;
- галочка `Вшить драйверы из input в образ` в ряду опций вверху вкладки. Порядок такой: секция `Драйверы этой машины` на той же вкладке показывает все сторонние пакеты драйверов карточками, сетевые (Wi-Fi, Ethernet, Bluetooth) отмечены сразу, этого хватает, чтобы свежая система вышла в сеть, остальное подтянет Windows Update; отметьте больше, если нужно, и нажмите `Экспорт драйверов` в строке навигации, каждый в свою папку с .inf, .sys и .cat; папку `Drivers` переносите внутрь `input` (путь «Источник» вверху окна) под любым именем и на любую глубину, программа сама найдёт каждый `.inf`; ставите галочку и собираете. Пакеты копируются в `Drivers\OS` сборки, конвертер включает `AddDrivers`, и DISM вшивает их в install.wim, так что установщик ставит их вместе с системой. Годятся только распакованные INF-пакеты, exe-установщик вендора нет; разрядность должна совпадать с образом; неподписанные драйверы потребуют тестового режима. Драйверы дисков и RAID, без которых установщик не видит диск, сюда не входят;
- без галочки пакет просто лежит в папке сборки, и скрипт можно запустить когда угодно, хоть на другой машине.

Пакет формируется с обновлениями внутри, с .NET 3.5 и с очисткой.

Обновления и дополнительные редакции вшивает в образ DISM, и конвертер берёт его из Windows ADK Deployment Tools. Без ADK он падает на системный DISM, а тот на Windows 11 25H2 не может обслуживать образ: сборка тогда молча выходит без обновлений и без редакций, голая база. Поэтому, пока ADK не установлен, кнопки скачивания в этом разделе затемнены с объяснением в подсказке, а внизу есть кнопка `Установить ADK`: она берёт adksetup.exe у Microsoft и ставит только Deployment Tools, около 100 МБ, с запросом прав администратора. После установки кнопки открываются сами. Если конвертер всё же что-то не смог, программа читает его журнал ошибок и сообщает об этом, а не считает такую сборку готовой.

Над редакцией стоят три кнопки-пресета «Вид образа»: `Business` выставляет Pro с Enterprise, Education, Pro Education и Pro for Workstations, как в образе business editions; `Consumer` выставляет Home и Pro в одном образе с Education, Pro Education и Pro for Workstations, как в образе consumer editions; `Только Pro` снимает всё лишнее. Кнопка `Edge (1)` в блоке приложений решает, класть ли браузер Edge в образ. Среда Edge WebView2 не затрагивается и остаётся в системе: это отдельный компонент, на нём работают и собираются приложения, от новых Outlook и Teams до сторонних программ.

Блок `Встроенные приложения` решает, какие Store-приложения попадут в образ. `Как у Microsoft` кладёт стандартный набор, `Нет` не кладёт ни одного, `Выбранные ниже` (по умолчанию) открывает список из 59 карточек, где отмеченные ставятся, а остальные не появятся в системе вовсе, и удалять их потом нечего. Три пресета `Набор приложений` заполняют список: `Минимум` (четыре системных пакета), `Работа` (плюс тринадцать инструментов и десять кодеков) и `Всё`; состав каждого в таблице ниже. Ряд `Включать в сборку дистрибутива` собирает балласт в кнопки-переключатели: ненажатая кнопка не пускает свою группу в образ, нажатая ставит её. По умолчанию все семь не нажаты, образ выходит с набором `Работа` и без Edge. Число в подписи это количество пакетов в группе, список лежит в подсказке кнопки: `Медиа-стек (4)` это Media Player, «Кино и ТВ», «Фотографии» и Clipchamp; `Edge (1)` это сам браузер, отдельной галочки для него нет; дальше `Xbox (6)`, `Teams и почта (6)`, `Bing и виджеты (6)`, `Промо и помощники (8)` и `Мелкие инструменты (2)`. Кнопки и карточки ниже показывают один и тот же выбор: снимите одну карточку группы, и кнопка погаснет. Механизм один для всех клиентских редакций Windows 11, не только для N: конвертер комментирует лишние строки в своём списке пакетов и не кладёт их в образ. OneDrive и Copilot это не Store-пакеты, они убираются уже после установки.

Наборы установки, кнопки ряда `Набор приложений`; каждая просто заполняет список карточек, а дальше его можно править руками или кнопками групп:

| Набор | Пакетов | Что ставится | Для кого |
|---|---|---|---|
| `Минимум` | 4 | только системные: Магазин, Покупки Store, Безопасность Windows, Установщик приложений | образ под сервер приложений или киоск, где ничего из Store не нужно, а WinGet и обновления Магазина остаются |
| `Работа` | 27 | системные, тринадцать инструментов (Блокнот, Windows Terminal, Калькулятор, Ножницы, Paint, Камера, Диктофон, Связь с телефоном, Часы, Записки, To Do, Погода, Power Automate) и десять кодеков | рабочая машина без развлечений и рекламы; это выбор по умолчанию, с ним собран эталонный образ |
| `Всё` | 59 | весь каталог, как у Microsoft, только список открыт для правки | когда нужно всё штатное, но с возможностью снять пару карточек |

Ряд `Вид образа` выше отвечает за редакции, а не за приложения: `Business` это Pro плюс Enterprise, Education, Pro Education и Pro for Workstations, `Consumer` это Home и Pro плюс Education, Pro Education и Pro for Workstations, `Только Pro` одна редакция. Наборы и вид образа сочетаются свободно.

| Группа | Сколько | Что внутри | По умолчанию |

Набор `Минимум` это четыре системных пакета без инструментов и кодеков, `Всё` включает все группы разом. OneDrive и Copilot в каталоге нет: это не Store-пакеты, они убираются уже после установки.

Про редакции честно: Microsoft раздаёт через UUP только потребительские Home и Pro с их N-вариантами, у Windows 10 ещё Team. Всё остальное UUP dump выводит из Pro при сборке, и это блок `Дополнительные редакции в ISO`: Enterprise, IoT Enterprise, IoT Enterprise K, Education, Pro Education, Pro for Workstations и Enterprise multi-session. Отмеченные добавляются в тот же образ рядом с базовой редакцией, в карточке версии они видны в подписи. LTSC так не получить - его нет ни в каталоге, ни среди выводимых редакций, Microsoft раздаёт LTSC только по корпоративным каналам. ARM в каталоге есть для всех тех же сборок, переключатель платформы.

У драйверов NVIDIA выбор идёт от поколения чипов, а не от конкретной карты: один файл драйвера закрывает несколько поколений, и список показывает то, что NVIDIA публикует для выбранного. Вариант `Мои карты` оставляет только версии, выпущенные для всех поколений из ряда галочек `Мои поколения`, который появляется под переключателем, - один драйвер на все карты в доме; отметки запоминаются в `config\vendor_nvidia.yaml` и возвращаются при следующем запуске. У каждой версии в подписи стоят дата, размер и отметки:

- `NVENC SDK 13.1` - поколение заголовков nv-codec-headers, под которое собран FFmpeg: сборка с такими заголовками заработает на этом драйвере и на любом новее; SDK 13.1 просит 610, SDK 13.0 - 570, SDK 12.2 - 551.76;
- `FFmpeg <= 8.0.1` - самая новая сборка FFmpeg из Audion Media Tools, у которой на этом драйвере работает аппаратное кодирование: 9.0.1 просит 610, 8.0.1 и 7.1.1 - 570, 7.1 - 551.76;
- `CUDA <= 13.0` - самый новый CUDA Toolkit, который драйвер поддерживает. CUDA обратно совместима: драйвер тянет и все тулкиты старше, а программа, собранная на CUDA 12.6, работает с любым драйвером от 560.76;
- `★ golden` - версии, которые в народе считают проверенными; такая карточка золотая.

Все списки лежат в `config\vendor_nvidia.yaml` и правятся руками: добавьте своё «золото», порог под новый SDK или поколение своих карт, и список это покажет при следующем открытии.

DLSS не скачивается как программа: это библиотека `nvngx_dlss.dll`, которую несёт каждая игра, а драйвер и NVIDIA App умеют подменять её на новую. Отдельные версии трёх библиотек - апскейлер, генерация кадров, реконструкция лучей - лежат здесь, чтобы подложить нужную в папку игры или держать под рукой для подмены.

Как это выглядит:

- платформа и продукт выбираются переключателями; `Весь каталог` у Blackmagic и `Все четыре` у Affinity показывают все продукты сразу, продукт написан перед каждой версией, а поле фильтра сужает список;
- версии лежат карточками с чекбоксами. Отметьте нужные и нажмите `Скачать` внизу - или нажмите кнопку на самой карточке, чтобы взять только эту сборку. Ряд `Выбрать` над карточками отмечает их по правилу: `Последняя стабильная` берёт самый новый финальный выпуск, пропуская беты и Insider, `★ Золотые` все карточки со звездой, `Снять` очищает выбор. Звезду и золотую рамку у NVIDIA получают драйверы из списка золотых, у Windows новейшая сборка каждого поколения, 22H2, 24H2, 25H2 и так далее, со свежим накопительным обновлением; остальные сборки поколения это история, и в списке из сотен строк золотые видно сразу. Кнопка со скрепкой только печатает ссылку в журнал и в `report\links.txt`, ничего не скачивая;
- каждая сборка ложится в свою папку `output\Vendors\<Производитель>\<имя архива>`, например `output\Vendors\Blackmagic Design\DaVinci_Resolve_Studio_21.0.4_Windows` или `output\Vendors\Affinity\affinity-photo-2.6.5`. Если папка назначения сама и есть ваш склад этого производителя, включите `Сразу в папку назначения`;
- прерванная загрузка докачивается: запустите ту же сборку ещё раз, файл продолжится с места обрыва. Готовый файл повторно не качается;
- zip распаковывается в свою папку, чтобы установщик был под рукой, и по умолчанию удаляется после распаковки. Оба действия отключаются галочками. exe, msix, dmg и tar остаются как есть.

Учётная запись не нужна нигде, кроме одного случая: бесплатная DaVinci Resolve выдаётся Blackmagic только после анкеты (имя, почта, телефон, адрес). Поля анкеты появляются внизу раздела, когда выбран этот продукт; они уходят напрямую на blackmagicdesign.com, учётная запись не создаётся, письмо подтверждать не нужно, и здесь ничего не сохраняется. Подписанные ссылки Blackmagic и Serif живут несколько часов, ссылки Affinity 3 постоянные.

## Драйверы этой машины

Секция `Драйверы этой машины` стоит на вкладке Windows (UUP dump) раздела загрузок от вендоров, между сборкой и версиями. Список строит `pnputil /enum-drivers`: по карточке на каждый сторонний пакет, впереди класс (Сеть, Bluetooth, Чипсет / система, Диски / RAID, Звук, Видео и так далее), затем исходное имя inf, поставщик и версия; встроенные драйверы Microsoft не показываются. Классы Сеть и Bluetooth отмечены при открытии, и только новейшая версия каждого драйвера, старые копии из хранилища остаются неотмеченными: свежей системе этого хватает, чтобы выйти в сеть, а остальные драйверы, и посвежее, принесёт Windows Update. Хотите больше, отметьте чипсет, диски, звук, хоть видеокарту, помня, что install.wim растёт на каждый пакет. Кнопка `Экспорт драйверов` в строке навигации вызывает `pnputil /export-driver` для каждой галочки и складывает пакеты папками с .inf, .sys и .cat; на машине ничего не меняется. Дальше эта папка идёт либо внутрь `input` для вшивки в образ, либо на свежую систему командой `pnputil /add-driver <папка>\*.inf /subdirs /install`.

## Служебные кнопки со сторонними инструментами

В разделе Windows (UUP dump), в строке навигации рядом с кнопкой ADK, есть `WinUtil`: утилита Криса Титуса для Windows, твики, чистка, установка программ, управление обновлениями. Она открывается в своём окне: в Windows Terminal, если он установлен, иначе в обычной консоли, с PowerShell 7, если он есть, иначе с Windows PowerShell 5.1. Скрипт скачивается с сайта автора при каждом запуске и сам просит права администратора, программа его не ждёт.  В разделе служебных процедур `Состояние лицензии Windows`: только чтение, редакция, канал лицензии и срок через штатный slmgr, вывод в журнал.

## Наборы Visual C++ (MSVC)

Старым играм и программам нужны рантаймы Visual C++ разных лет. Обычно это самая запутанная часть системы, поэтому она разложена по трём местам.

| Где | Что там |
| --- | --- |
| `MSVC рантайм (2015+)` | Официальные пакеты Microsoft x86 и x64. Современной системе больше ничего не нужно. |
| `Advanced: MSVC 2005-2013` | Официальные пакеты по одному на год и разрядность - только для древнего софта. Обновления по ним не приходят никогда: производитель заморозил эти сборки. |
| `Классические скрипты` | Два готовых набора: `MSVC All-in-One (TechPowerUp)` и `MSVC AIO (abbodi1406)`. У каждого есть кнопка скачивания и кнопка перехода на страницу выпуска. |

Наборы удобнее поштучной установки: один заход ставит все рантаймы сразу и включает 2012 год, для которого пакета в WinGet не существует вовсе. Их собирают и обновляют авторитетные сборщики, поэтому для старого семейства лучше брать именно их.

Действие `Проверить рантаймы MSVC` показывает, что реально установлено на машине, какая версия доступна и нужно ли что-то делать. С него стоит начинать, если непонятно, чего не хватает.

Установка рантаймов меняет систему, поэтому Audion Get Tools сначала показывает подтверждение. Приложение должно быть запущено от имени администратора - без этого установка не начнётся и вы увидите об этом сообщение.

Удаление рантаймов не разделено на группы: убираются все девять сразу. Так и задумано - этот набор надёжнее снести целиком и поставить начисто, чем чинить по частям.

## AI Package Planner

Раздел Audion Get Tools для LLM-подбора Windows/WinGet пакетов, проверки точных ID и запуска выбранных действий через обычные защищённые пути Audion.

### Назначение

`AI Package Planner` помогает пользователю описать задачу обычным языком, получить короткий план пакетов, проверить предложения через WinGet search и затем выполнить только выбранные точные ID.

Раздел не является отдельным установщиком. Он не должен обходить существующие сценарии установки, обновления, pin, проверки наличия и удаления. LLM только помогает подобрать варианты и сформировать проверяемый план.

Основная ценность раздела:

- подобрать программы по человеческому запросу;
- уменьшить ошибки в WinGet package ID;
- показать пользователю план до установки;
- дать точечный поиск и точечные операции по exact ID;
- сохранить ключи, модели и prompt-шаблоны в управляемом GUI-контуре.

### Главная модель работы

Раздел разделён на две вкладки:

| Вкладка | Для чего нужна |
| --- | --- |
| `Planner` | Задача для AI, шаблон инструкции, редактор инструкции, сборка плана, поиск WinGet и запуск выбранных exact ID. |
| `Models` | Выбор провайдера OpenAI/Gemini, ключей, моделей, ручных override, reasoning и проверка модели. |

Верхняя кнопка справа в строке раздела:

`ЗАПУСТИТЬ ВЫБРАННОЕ ПРИ ПОМОЩИ AI`

Она открывает финальную форму запуска выбранных пакетов из последнего AI-плана. Это главный пользовательский CTA после того, как план уже собран и проверен.

Кнопка `Собрать план` остаётся первой кнопкой в блоке `Действия`, потому что это начальный шаг планирования, а не финальный запуск.

### Поля Planner

#### Задача для AI

Что нужно найти или подготовить сейчас.

Примеры:

- `Найди Media Player Classic Black Edition через WinGet.`
- `Подготовь Windows-машину для Dev/Media.`
- `Подбери инструменты для записи экрана, монтажа и конвертации видео.`

Это обязательное поле для сборки AI-плана. Без задачи LLM не понимает, что именно нужно подобрать.

#### Шаблон инструкции

Сохранённый шаблон поведения AI.

Выбор шаблона загружает текст в поле `Инструкция AI-планировщика`. Сам выбор шаблона не запускает сканирование установленных пакетов, не вызывает LLM и ничего не устанавливает.

Кнопки рядом с селектом:

| Иконка | Действие |
| --- | --- |
| `sync` | Обновить список шаблонов. |
| `save` | Сохранить текущую инструкцию в cache prompt. |
| `push_pin` | Закрепить выбранный шаблон. |
| `block` | Снять закрепление. |
| `delete` | Удалить выбранный шаблон из кэша. |
| `backspace` | Очистить редактор инструкции. |

#### Инструкция AI-планировщика

Правила, как AI должен думать и оформлять план.

Обычно пользователь не обязан редактировать это поле. Достаточно выбрать шаблон инструкции или оставить дефолтный prompt.

Инструкция задаёт поведение:

- сначала предложить варианты;
- не устанавливать ничего на этапе планирования;
- проверять или уточнять WinGet ID;
- отмечать риски и неоднозначности;
- держать ответ коротким и практичным.

#### Сканировать установленные ID

Передаёт LLM список уже установленных WinGet ID.

Это помогает не предлагать то, что уже стоит на машине. Установленное состояние считается только по результату сканирования, а не по известным группам Audion.

#### Передать известные группы Audion

Передаёт LLM кураторские списки проекта как контекст.

Важно: известные группы Audion - это варианты и пресеты, а не доказательство того, что пакет установлен.

#### Кандидатов поиска

Сколько результатов `winget search` собирать для каждого предложенного пакета.

Малое значение быстрее и чище. Большее значение полезно для неоднозначных запросов.

### Действия Planner

| Действие | Что делает | Тип |
| --- | --- | --- |
| `Собрать план` | Отправляет задачу и инструкцию в LLM, затем проверяет кандидаты через WinGet search. | Безопасное |
| `Поиск WinGet` | Ищет пакеты по названию, задаче или точному ID и пишет отчёт. | Безопасное |
| `Запустить выбранное из AI-плана` | Открывает форму выбора exact ID из последнего плана и действия над ними. | Опасное при install/update/uninstall |
| `Добавить точный ID в список` | Добавляет проверенный ID в выбранный config-список и GUI-группу. | Безопасное |
| `Установить точный ID` | Устанавливает один exact ID через обычный путь Audion. | Опасное |
| `Обновить точный ID` | Обновляет один exact ID через обычный путь Audion. | Опасное |
| `Удалить точный ID` | Удаляет один exact ID через защищённый путь Audion. | Опасное |

Опасные действия проходят через стандартное подтверждение Audion.

### Сборка AI-плана

При нажатии `Собрать план` сервис выполняет цепочку:

1. Берёт `Задача для AI`.
2. Берёт prompt из `Инструкция AI-планировщика` или из выбранного шаблона.
3. При необходимости сканирует установленные WinGet ID.
4. При необходимости добавляет известные группы Audion как контекст.
5. Вызывает выбранный LLM-провайдер.
6. Требует JSON-ответ по схеме плана пакетов.
7. Нормализует предложения модели.
8. Проверяет кандидаты через `winget search`.
9. Сохраняет последний план в cache.
10. Пишет Markdown/JSON отчёт в `report\`.

LLM должна возвращать структурированный объект с кратким summary, списком packages и notes.

Каждый пакет в плане содержит:

- отображаемое имя;
- запрос поиска;
- предполагаемый или точный WinGet ID;
- группу Audion;
- предполагаемое действие;
- причину выбора;
- риск или заметку для проверки.

### Валидация WinGet ID

Планировщик не доверяет ID только потому, что их предложила LLM.

Статусы проверки:

| Статус | Значение |
| --- | --- |
| `validated_exact` | Точный ID найден через exact WinGet search. |
| `single_search_candidate` | ID не был указан, но поиск дал один сильный кандидат. |
| `search_candidates` | Найдены варианты, нужен выбор человеком. |
| `id_not_found` | Указанный ID не найден. |
| `review_required` | Нужна ручная проверка. |

Для запуска из AI-плана в чекбоксы попадают только пригодные exact ID.

### Запуск выбранного из AI-плана

Финальный сценарий открывается верхней CTA `ЗАПУСТИТЬ ВЫБРАННОЕ ПРИ ПОМОЩИ AI` или кнопкой `Запустить выбранное из AI-плана` в action-grid.

В форме есть:

- `Действие`;
- список `Точные ID последнего AI-плана`;
- импорт/экспорт YAML для чекбоксов;
- финальная кнопка запуска выбранной операции.

Доступные действия:

| Действие | Что делает |
| --- | --- |
| `Установить отсутствующие` | Устанавливает выбранные exact ID через пакетный install. |
| `Обновить установленные` | Обновляет выбранные exact ID через пакетный update. |
| `Закрепить установленные` | Добавляет ID в pins и применяет blocking pin. |
| `Проверить наличие` | Проверяет наличие выбранных ID. |
| `Удалить выбранные` | Удаляет выбранные exact ID через пакетный uninstall. |

Этот путь использует `winget_service._run_package_batch`, то есть остаётся в общей логике Audion для пакетных действий.

### Точечные exact-ID операции

Раздел поддерживает операции без LLM-плана:

#### Поиск WinGet

Поле `Что искать` принимает:

- название приложения;
- имя производителя;
- задачу;
- точный WinGet ID.

Опция `Искать точный ID` переключает поиск в exact-режим.

Результаты пишутся в `report\<timestamp>_ai_search_winget\winget_search.md` и JSON.

#### Добавить точный ID в список

Добавляет проверенный package ID в выбранный список:

- `system`
- `dev`
- `ai`
- `pkms`
- `office`
- `media_images`
- `media_audio`
- `media_video`
- `network`
- `hardware`
- `custom`
- `pins`

Для GUI-групп ID добавляется в `config\tool_manifest.yaml`, чтобы появился обычный чекбокс.

#### Установить точный ID

Запускает обычный Audion install-by-ID путь.

#### Обновить точный ID

### Безопасность

Ключевые правила:

- LLM не выполняет установку сама.
- План сначала показывается пользователю.
- Запускаются только выбранные exact ID.
- Опасные действия идут через подтверждение Audion.
- WinGet ID проверяются через search перед попаданием в план.
- Известные группы Audion не считаются установленным состоянием.
- API keys не пишутся в кэш и отчёты.
- Protected uninstall остаётся в обычном защищённом контуре Audion.

### Граница MCP/WinGet

Раздел проектировался как AI-слой над WinGet: агент сначала планирует, затем проверяет, затем пользователь выбирает exact ID.

Даже при развитии WinGet MCP логика безопасности остаётся той же:

- plan first;
- validate exact IDs;
- user review;
- execute after approval;
- never bypass Audion package paths.

#### Что сейчас есть в самом WinGet (проверено на 1.29.280)

`winget mcp` печатает JSON-фрагмент для подключения `WindowsPackageManagerMCPServer.exe` к любому MCP-клиенту. Сам сервер (`winget-mcp`) отдаёт ровно два инструмента:

- `find-winget-packages` — поиск и список обновляемых пакетов (`query`, `upgradeable`), read-only;
- `install-winget-package` — установка или обновление (`identifier`, `source`, `upgradeOnly`), destructive.

Оба — подмножество того, что Audion Get Tools уже делает напрямую: поиск для валидации плана и установка/обновление по точному ID. Через MCP это шло бы без живого ConPTY-прогресса, без логов и отчётов и мимо проверки защищённых ID, поэтому планировщик по-прежнему вызывает WinGet сам. `Health / Doctor` показывает путь к MCP-серверу — его можно подключить к внешнему MCP-клиенту, не меняя работу приложения.

### Загрузки от вендоров

DaVinci Resolve, Affinity, драйверы и программы NVIDIA, образы Windows с обновлениями внутри: все выпущенные версии прямо от источника, каждая сборка в свою папку.

Подсказка: WinGet даёт текущий выпуск; здесь каталог самого производителя перечисляет все версии. Переключите производителя, выберите платформу и продукт, отметьте версии или нажмите кнопки на карточке. Загрузки ложатся в output\Vendors\<Производитель>\<имя архива>.

#### Поля

**Производитель** — вкладки вверху формы.
- Подсказка: Чей каталог смотреть. Windows (UUP dump): каждая сборка Windows 11 и 10 со своим накопительным обновлением, пакетом скриптов, который собирает ISO из файлов самой Microsoft. TechPowerUp: драйверы AMD, Intel и Qualcomm плюс утилиты, мониторинг, бенчмарки и прошивальщики BIOS видеокарт с сайта, все версии. NVIDIA: драйверы Game Ready и Studio по поколениям чипов, NVIDIA App, Broadcast, CUDA Toolkit и DLSS. Blackmagic: Resolve, Fusion, RAW, Desktop Video и весь каталог. Affinity: Photo, Designer, Publisher 2 и единая Affinity 3.
- По умолчанию: Windows (UUP dump)
- Варианты: Windows (UUP dump); TechPowerUp — Каталог TechPowerUp со всей историей версий каждой записи: драйверы AMD, Intel и Qualcomm, утилиты настройки (DDU, NVCleanstall, ThrottleStop...), мониторинг (GPU-Z, CPU-Z, AIDA64), бенчмарки и прошивальщики BIOS видеокарт. Драйверы NVIDIA и DLSS остаются на вкладке NVIDIA.; NVIDIA; Blackmagic Design; Affinity

**Раздел** — ряд переключателей, один вариант.
- Подсказка: Раздел каталога TechPowerUp: драйверы, утилиты настройки, мониторинг, бенчмарки или прошивальщики BIOS видеокарт. Ряд продуктов ниже меняется вместе с ним. Драйверы NVIDIA и библиотеки DLSS остаются на вкладке NVIDIA.
- По умолчанию: Драйверы
- Показывается, когда: Производитель = «TechPowerUp»
- Варианты: Драйверы; Утилиты; Мониторинг; Бенчмарки; BIOS видеокарт

**Продукт** — ряд переключателей, один вариант.

- По умолчанию: да
- Показывается, когда: Производитель = «Windows (UUP dump)»

**Удалить кэш после ISO** — галочка.
- Подсказка: Когда образ перенесён в папку назначения, папка сборки в UUP в корне диска программы, со скриптами конвертера и 9 ГБ файлов Microsoft, удаляется. Выключено: папка остаётся, и ту же сборку можно пересобрать с другими приложениями без повторного скачивания.
- По умолчанию: нет
- Показывается, когда: Производитель = «Windows (UUP dump)»; Сразу собрать ISO = «True»

**Вшить драйверы из input в образ** — галочка.
- Подсказка: По шагам. 1) Получите пакеты драйверов: откройте «Драйверы этой машины» в списке операций, сетевые уже отмечены, отметьте ещё что хотите, нажмите «Экспорт»: пакеты лягут в output\Drivers папками с .inf, .sys и .cat; или скопируйте такие папки откуда угодно. 2) Положите их куда угодно внутрь входной папки (путь «Источник» вверху окна): папку Drivers из экспорта как есть, папку с именем ноутбука или пакеты прямо сверху, программа сама найдёт каждый .inf. 3) Поставьте эту галочку и соберите ISO: каждый пакет копируется в Drivers\OS сборки, DISM вшивает их в install.wim, и установщик Windows ставит их вместе с системой. Работают только распакованные INF-пакеты, exe-установщик вендора не годится; разрядность должна совпадать с образом (x64); неподписанные драйверы потребуют тестового режима на целевой машине. Драйверы дисков и RAID, без которых сам установщик не видит диск, сюда не входят.
- По умолчанию: нет
- Показывается, когда: Производитель = «Windows (UUP dump)»

**Сразу в папку назначения** — галочка.
- Подсказка: Без уровней Vendors\<Производитель>: папка каждой сборки ложится прямо в папку назначения. Для склада, который сам и есть папка производителя.

##### Установить ADK

Зачем: конвертер UUP dump вшивает накопительное обновление, дополнительные редакции и драйверы в образ через DISM, и берёт этот DISM из Windows ADK Deployment Tools; системный DISM более новой машины отказывает, и образ выходит без обновлений. ##### WinUtil

Открыть утилиту Криса Титуса для Windows (irm https://christitus.com/win | iex) в отдельном терминале: твики, чистка, установка программ, управление обновлениями. Запускается в Windows Terminal, если он установлен, иначе в обычной консоли; PowerShell 7, если есть, иначе Windows PowerShell 5.1. Скрипт скачивается с сайта автора при запуске и сам просит права администратора в своём окне.

_меняет систему, перед запуском спрашивает подтверждение; показывается, когда: vendor = uupdump_

##### Экспорт драйверов

По шагам. 1) В секции «Драйверы этой машины» ниже сетевые драйверы уже отмечены; отметьте, что ещё хотите. 2) Нажмите эту кнопку: pnputil /export-driver скопирует каждый отмеченный драйвер в output\Drivers, по папке на пакет с .inf, .sys и .cat; на машине ничего не меняется. 3) Перенесите папку Drivers во входную папку (путь «Источник» вверху окна), под любым именем. 4) Поставьте галочку «Вшить драйверы из input в образ» в ряду «Опции» вверху этой вкладки вместе с «Сразу собрать ISO»: при сборке программа найдёт все .inf где угодно внутри input, и DISM вошьёт пакеты в install.wim, так что установщик Windows поставит их вместе с системой. Без этой галочки драйверы остаются в input и не вшиваются.

_безопасное действие, подтверждения не просит; показывается, когда: vendor = uupdump_
